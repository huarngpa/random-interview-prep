# Design Priority

This is the design shortlist that matters now.

The main correction to the earlier prep is:

- we still want the Forge / manufacturing context
- but we also want to be ready for a more generic systems-design prompt

So the best order is:

## Step 1: Learn The Conversation Flow

Read:

- [System Design Arc](../grok-tech-screen/design/system-design-arc.md)

Why:

- this is the practical interview flow
- it helps you sound natural instead of robotic

## Step 2: Refresh The Generic Shapes

Read:

- [Modern Primer Shapes](../grok-tech-screen/design/modern-primer-shapes.md)
- [Generic Design Translations](../grok-tech-screen/design/generic-design-translations.md)

Why:

- this protects you if the prompt is generic rather than explicitly factory-shaped

## Step 3: Keep The Highest-Yield Anduril-Specific Designs

Read:

1. [MES For Mixed-Model Production](../grok-tech-screen/design/mes-for-mixed-model-production.md)
2. [Traceability And Genealogy](../grok-tech-screen/design/traceability-and-genealogy.md)
3. [Engineering Change Rollout](../grok-tech-screen/design/engineering-change-rollout.md)

Why these:

- together they cover workflow, audit/history, and safe rollout
- those are the deepest recurring themes in the Forge-style material

## Step 4: Keep One Visibility And One Exception Design In Reserve

Read:

- [Real-Time Factory Visibility](../grok-tech-screen/design/real-time-factory-visibility.md)
- [Quality Hold And Rework Management](../grok-tech-screen/design/quality-hold-and-rework-management.md)

Why:

- these are strong backups if the prompt lands more on observability or exception workflows

## What To Say To Yourself

The mental model should be:

- start generic
- anchor on users and workflow
- define entities
- sketch architecture
- walk read/write flows
- then bring in concrete stack choices

That is much more valuable now than reading more new design material.
