# What Matters Now

This is the short version.

You are not preparing from scratch anymore.

You are trying to maximize interview performance in the final stretch.

That means the goal is no longer:

- build the most complete Anduril prep library possible

It is:

- focus on the highest-signal material for the actual loop in front of you

- [System Design Arc](../grok-tech-screen/design/system-design-arc.md)
- [Design Study Guide](../grok-tech-screen/design/study-guide.md)

- [Modern Primer Shapes](../grok-tech-screen/design/modern-primer-shapes.md)
