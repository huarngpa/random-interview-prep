This folder is a predicted-proxy set built from the historical Anduril trends.

It is not claiming these are the exact next questions.

The point is:

- Anduril has shown a clear taste profile
- new cycles usually preserve taste while changing the skin
- these problems are strong proxies for the next likely shapes

## How To Use This Folder

1. Start with the "Why It Is Likely" section.
2. Try to identify the pattern family yourself.
3. Read the principle section before looking at the solution.
4. Practice implementing from memory.
5. Return later and see whether the principle, not the code, is what you retained.
