# Solved Tech Screen Problems

These are the six highest-yield Anduril screen problems, rewritten as self-contained notes for this narrower sprint pack.

Each problem includes:

- why it is likely in the screen
- why Anduril would care about this pattern
- framework classification
- a concrete solving walkthrough
- a Python reference solution

## How To Use This Folder

1. Try to classify the problem yourself first.
2. Read the "Why Anduril Asks This" section.
3. Study the invariant and walkthrough.
4. Re-implement from memory.
5. Practice saying out loud why this problem maps to factory software or internal tools.
