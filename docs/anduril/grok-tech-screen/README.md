# Anduril Tech Screen Notes

This folder captures the separate "two Mediums in 45 minutes" prep angle for Anduril.

It is intentionally narrower than the broader [Anduril Study Pack](../README.md).

The main Anduril folder is trying to answer:

- what has Anduril asked over time?
- what are they likely to ask in the next cycle?

This folder is trying to answer a more tactical question:

- if the screen is a `45` minute HackerRank with `2` Medium problems, what should we train right now?

The guidance here is based on the user-provided Grok writeup plus the historical Anduril problem set already captured in this repo.

## Working Assumption

For this kind of screen, the highest-probability shape is:

1. one clean, fast Medium you should finish comfortably
2. one slightly meatier Medium with either grid traversal, simulation, or stack/BFS depth

That means we should optimize for:

- fast pattern recognition
- clean implementation
- low bug rate
- being able to explain complexity and tradeoffs clearly

Not for:

- exotic hard-problem tricks
- fancy abstractions
- over-preparing on rare categories

## Why This Set

This set is attractive for a `45` minute screen because it covers the most common Anduril-friendly shapes without over-indexing on rare hard questions:

- matrix traversal
- BFS on a grid
- simulation
- monotonic stack
- string/hash-map classification

In other words, these are the problems most likely to make the actual screen feel familiar.
