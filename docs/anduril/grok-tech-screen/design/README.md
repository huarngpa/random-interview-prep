# Anduril Full-Loop Design Pack

This folder is the design-interview companion to the narrower HackerRank prep pack.

The coding screen is about:

- solving two Mediums quickly

This folder is about what likely happens later in the loop:

- systems design for Forge / ArsenalOS
- operational software for manufacturing
- internal platforms that sit close to the physical world

The goal here is not to memorize one perfect architecture.

It is to build the right instincts for answering a design question in this domain:

- model the factory as a stateful operational system
- separate definition-time data from execution-time data
- respect traceability, revisioning, and auditability
- design for live production environments that cannot stop
- make the operator path simple and trustworthy
