# Anduril Problem Framework Notes

This folder applies the interview framework to every problem in the referenced Anduril CSV. Each note answers the same questions: what structure the problem has, which pattern the framework points to, what invariant makes the solution trustworthy, what the implementation skeleton looks like, which mistakes are most common, and what a reference Python solution looks like.

## How To Use These Notes

1. Read the problem statement first without the note open.
2. Classify the problem using the questions in the main framework doc.
3. Guess the pattern and say the invariant out loud.
4. Open the corresponding note and compare your reasoning against it.
5. Then implement the problem in the practice harness if you want repetition.
